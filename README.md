# Forbidden Psalm Builder

A web-based character and warband management tool for Forbidden Psalm tabletop RPG.

## Features

- **Multiple Game Variants**: Support for 28 Psalms, End Times, and The Last War
- **Character Management**: Create and manage characters with stats, equipment, and progression
- **Warband Economics**: Track gold, equipment, and warband stash
- **Level-Up System**: Spend XP to improve characters and resurrect fallen heroes
- **Equipment System**: Manage weapons, armor, ammo, and consumables
- **Custom Items**: Create custom equipment for your campaigns
- **Export/Import**: Share warbands in JSON or export to markdown

## Getting Started

Visit the live app: **[https://luismars.github.io/forbidden-psalm/](https://luismars.github.io/forbidden-psalm/)**

## Development

Built with:
- .NET 9
- Blazor WebAssembly
- Bootstrap 5

### Running Locally

```bash
cd ForbiddenPsalmBuilder
dotnet run --project ForbiddenPsalmBuilder.Blazor
```

### Running Tests

```bash
dotnet test
```
